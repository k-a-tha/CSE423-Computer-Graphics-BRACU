# Interactive 2D Graphics

This directory contains interactive 2D graphics projects developed using **Python**, **PyOpenGL**, and **GLUT**.

## Projects

### 1. House in Rainfall

An interactive 2D scene featuring:

- Animated rainfall
- Adjustable rain direction
- Day and night transition
- Keyboard interaction

---

### 2. Amazing Box

An interactive particle simulation featuring:

- Random particle generation
- Random movement
- Boundary collision
- Speed control
- Blinking effect
- Freeze/Resume functionality

---

## Technologies

- Python
- PyOpenGL
- OpenGL
- GLUT
